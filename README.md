# ATML Assignment 0: Introduction to Deep Learning Models

This repository contains the code implementations for Assignment 0 of Advanced Topics in Machine Learning.

## Repository Structure
* `/notebooks`: Contains the four Jupyter Notebooks corresponding to the assignment tasks.
  * `task1_resnet.ipynb`: CNN baseline, residual connections, and transfer learning.
  * `task2_vit.ipynb`: Vision Transformer attention visualization and patch-masking experiments.
  * `task3_clip.ipynb`: Zero-shot classification, modality gap analysis, and Procrustes alignment.
  * `task4_vae.ipynb`: Variational Autoencoder implementation for MNIST generation.
