# ATML Assignment 0: Introduction to Deep Learning Models

This repository contains the code implementations for Assignment 0 of Advanced Topics in Machine Learning.

## Repository Structure
* `/notebooks`: Contains the four Jupyter Notebooks corresponding to the assignment tasks.
  * `atml-task1.ipynb`: CNN baseline, residual connections, and transfer learning.
  * `atml-task2.ipynb`: Vision Transformer attention visualization and patch-masking experiments.
  * `atml-task3.ipynb`: Zero-shot classification, modality gap analysis, and Procrustes alignment.
  * `atml-task4.ipynb`: Variational Autoencoder implementation for MNIST generation.
